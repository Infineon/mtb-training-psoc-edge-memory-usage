# PSOC™ Edge Training - Understanding PSOC™ Edge Memory Usage

This training provides an overview of the PSOC™ Edge memory architecture and the different
memory technologies used in these devices. The presentation discusses low-power memory
considerations, techniques for reducing power consumption related to memory usage, and how to
achieve balanced energy efficiency in a PSOC™ Edge application.
The session includes hands-on labs explaining how to perform common memory management
tasks, such as placing code and data in memory sections and configuring memory retention.

## Device family
- [PSOC™ Edge](https://www.infineon.com/products/microcontroller/32-bit-psoc-arm-cortex/32-bit-psoc-edge-arm)

## Duration
- 90 min, including the video and hands-on labs

## Agenda
1. PSOC™ Edge memory architecture
2. PSOC™ Edge memory technologies
3. Lab 1: Assigning code and data to custom linker sections
4. Lab 2: Assigning a source file to a linker section
5. PSOC™ Edge architecture and memory access
6. Lab 3: Placing and executing code from RRAM
7. Lab 4: Placing and executing code from SRAM
8. PSOC™ Edge memory tradeoffs
9. Lab 5: Low-power memory considerations

## Expected Outcome
- Become familiar with the PSOC™ Edge memory architecture and supported memory technologies
- Understand the tradeoffs of PSOC™ Edge memories
- Gain hands-on experience with common memory management and allocation tasks
